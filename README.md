# How to Run This Code Locally
    If you wish to clone this repository and run the practice files locally, follow these steps:

    1.  Clone the repository:
        git clone https://github.com/Shubhankar-Bende/Learning_Typescript
    
    2.  Install dependencies:
        npm install
    
    3.  Compile and run a specific TypeScript file using `ts-node`:
        npx ts-node [filename]
